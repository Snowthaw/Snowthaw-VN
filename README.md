# Snowthaw-VN
基于日本轻小说  《モブ少女がラスボス魔女を幸せにするまで》制作的非商业同人视觉小说项目。
目前完成了原作前两卷内容。

> 这是个人兴趣项目，并非官方作品。
> 项目存在很多Bug，部分说话人、背景对不上（日本轻小说不标注说话人人名，ai错判说话人了）、游戏cg太短（一两句话就切过去了）、Live2D差分不明显等等

## 项目内容

目前游戏包含：

- 2 卷小说剧情
- 6636 条日语角色配音
- 180 张背景图片（我是准备了那么多正式的，但gpt编辑时可能没全部编进去）
- 93 张角色立绘及表情 / 动作差分（同上）
- 26 张游戏 CG
- 10+ 套日语 GPT-SoVITS 语音模型准备的配音
- 3 个角色的简单 Live2D
- 标题页面动态壁纸
- 部分技能 / 魔法视觉特效
- BGM、音效、角色语音
- 完整 Ren'Py 视觉小说界面

最终PC构筑版约 3GB。

## 制作方式

### 游戏引擎

- Ren'Py

### 标题页面动态壁纸

- GPT Image：角色 / 背景图片生成与拼合
- Gemini Omni 1.1 Flash：动态视频制作

### 角色立绘

共 93 张角色立绘及其表情、动作差分。

主要使用：

- ChatGPT / GPT Image

图片并非批量一次生成完成，而是经过多轮提示词修改、构图调整、画风校正和局部重做。

### 背景与 CG

- 180 张背景图
- 26 张游戏 CG
- 主要使用 ChatGPT / GPT Image 制作

### Live2D

目前有 3 个角色制作了简单 Live2D。

工作流主要由 ChatGPT：

- 在 GitHub 检索相关项目
- 下载并配置工具
- 规划单图 → 分层 → 自动绑定 → Live2D 的制作流程

目前 Live2D 仍存在一些 Bug。

### 角色配音

配音使用：

- GPT-SoVITS
- 10+ 套日语角色语音模型

游戏目前共有：

**6636 条配音**

角色语音前后重置 / 重配过约 6 轮。

2026-09-28 Snowthaw02 配音更新：

- 罗泽莉卡继续使用已经完成的艾丝妲模型版本：4292 条
- 其余角色使用 `语音资源2` 中的 15 套新模型重新配音：2344 条
- 每套模型均使用同源参考音进行试配
- 旧版音频仅保留在本地开发副本中，不包含于正式发行版

本轮使用的具体配音模型见项目展示图。

### 对话与界面

- 对话框调整：人工 + ChatGPT
- 角色显示位置 / 比例调整：人工 + ChatGPT
- 说话人核对：ChatGPT 辅助，每轮约 400 条进行检查

### 翻译

当前文本基于已有 EPUB 中文版本及 AI 辅助处理。

原始 EPUB 中文文本具体来自轻小说机翻机器人版本还是后续 ChatGPT 翻译，目前没有完全确认。

### 音乐

部分音乐来源于游戏资源解包文件。

## 开发规模

单人，课间，半个月
ChatGPT 的累计使用量大概有8亿token

其中图片制作占用了大量反复修改流程，主要原因包括：

- 角色画风统一
-视觉印象、朦胧感、2d、不要写实、背景简化（ai生图容易很杂很脏）、避免空间立体感
- 构图修正
- 五官 / 比例调整
- 背景风格统一
- 表情差分
- CG 重绘
- 角色位置调整

因此大部分图片无法简单批量生成。
